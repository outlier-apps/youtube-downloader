# YouTube Downloader

Programa para Windows que baixa vídeos (MP4) e músicas (MP3) do YouTube.

**Baixar:** [YouTube-Downloader.exe](https://github.com/outlier-apps/youtube-downloader/releases/latest/download/YouTube-Downloader.exe)

Precisa de uma chave de ativação, vendida na Basefy.

## Requisitos

- Windows 10 ou 11 (64 bits)
- Internet

## Como usar

1. Baixe e abra o `YouTube-Downloader.exe`. Ele cria um atalho na Área de Trabalho.
2. Cole a chave de ativação e clique em **Ativar**.
3. Cole o link do YouTube, escolha MP4 ou MP3 e clique em **Baixar agora**.

Se o Windows mostrar "O Windows protegeu o computador", clique em **Mais informações** e depois em **Executar assim mesmo**.

## Componentes de terceiros

Este programa inclui o [FFmpeg](https://ffmpeg.org) (licença GPL), cujo código-fonte está disponível em https://ffmpeg.org/download.html, e usa o [yt-dlp](https://github.com/yt-dlp/yt-dlp) (Unlicense).
